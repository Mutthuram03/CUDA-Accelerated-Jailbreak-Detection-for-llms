# Exploratory Data Analysis & Prototyping Notebooks

This directory contains Jupyter notebooks for exploratory data analysis (EDA), prompt length distributions, vocabulary overlap inspections, and feature visualization.

## Best Practices
1. **No Data In Notebook Outputs**: Clear outputs containing sensitive or raw prompt data before committing.
2. **Reproducibility**: Set seeds and reference standardized scripts from `src/` rather than defining ad-hoc functions inside cells.
3. **Drafting Ground**: Notebooks are meant for rapid visualization; production and evaluation logic must reside in `src/` and `experiments/`.
