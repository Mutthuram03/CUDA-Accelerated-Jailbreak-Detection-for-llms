Research Methodology & Formulation Mapping

Direct correspondence between research paper equations (1)–(26) and system implementation

Mathematical Formulations
Eq. (1)–(5) • Text Preprocessing & Cipher Detection

x̃i = Normalization(xi). Normalizes input strings using Unicode NFKC, eliminates zero-width whitespace (U+200B, U+FEFF), and inspects token entropy for Base64 and hexadecimal payloads.

Eq. (6)–(8) • Hybrid Feature Representation

zi = [zi(w) || zi(c) || zi(s)]. Concatenates word n-grams (1,2), character n-grams (2,5), and scalar structural features (Length, Diversity Ratio Rdiv, Shannon Entropy).

Eq. (9)–(13) • Classification Engine & Logit

pi = σ(zi w + b) = 1 / (1 + e-(zi w + b)). L2-regularized logistic sigmoid classification with calibrated decision threshold τ = 0.47 optimizing False Positive Rate ≤ 1.67%.

Eq. (14)–(15) • Three-Way Risk Routing Policy

d(pi) ∈ {allow, flag, block}. Queries with pi < τlow are forwarded directly; τlow ≤ pi < τhigh are escalated for review; pi ≥ τhigh are dropped instantly.

Eq. (16) • Probability Calibration (ECE)

ECE = ∑ (|Bm|/N) |acc(Bm) - conf(Bm)|. Achieved empirical ECE = 0.0079 (< 0.01), confirming calibrated confidence scores.

Eq. (19)–(26) • Hardware Latency & Throughput

Ttotal = Tpre + TH2D + Tkernel + TD2H + Tpost. Sub-millisecond GPU execution on NVIDIA GeForce RTX 4060 Laptop GPU with throughput Θ(B) exceeding 80,000 queries/second.
