# Measured Results & Artifacts

This directory stores reproducible evaluation metrics, timing outputs, and visualization figures generated by experiment runs.

## Storage Policy

1. Raw metric files (`.json`, `.csv`) and figures (`.png`, `.pdf`) are ignored by Git via `.gitignore` to avoid binary churn.
2. Official milestone summary tables and benchmark logs will be documented in version-controlled markdown reports in this folder or in `docs/`.
3. Never fabricate or invent results; every reported metric must link to an automated script execution log with hardware configuration details.

## Directory Structure

```
results/
├── README.md               # Results storage policy and summary logs
├── metrics/                # Machine-readable JSON/CSV metric evaluations (ignored by git)
│   └── .gitkeep
└── figures/                # ROC curves, confusion matrices, latency vs batch size plots (ignored by git)
    └── .gitkeep
```
